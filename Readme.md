# SteamBundleBot 🚀🃏

[![Python](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Docker](https://img.shields.io/badge/docker-ready-blue.svg)](https://www.docker.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**SteamBundleBot** is a Python automation script designed to scan the Steam store and Humble Bundle for discounted games and bundles. It determines their **net profitability** based on the resale value of their *Steam Trading Cards* on the Steam Community Market.

## ✨ Core Features

- 🔍 **Bundle & Game Scraping**: Automatically fetches available bundles and special offers directly from the Steam store and Humble Bundle.
- 📉 **Profitability Calculation**: Queries the Steam Community Market to estimate average card values. It dynamically accounts for Steam's 15% market tax and includes a probabilistic 5% EV bump for Foil card drops.
- 💎 **"Near-Free" Detection**: Identifies "Almost Free" offers where the return on investment (ROI) is 95% or higher, allowing you to grow your Steam library for pennies.
- 🛡️ **Intelligent Filtering**: Automatically excludes games you already own via the Steam Web API to ensure accurate calculations.
- 💾 **Local Database**: Uses SQLite to remember previously scanned bundles and profitable offers, preventing notification spam.
- ⏰ **Full Automation**: Designed to run automatically every day at 21:00 as a background task.
- 📩 **Discord Notifications**: Sends detailed *Rich Embeds* via a Discord Webhook, displaying the exact profits and ROI generated by the found offers.

## 📋 Prerequisites

- **Python 3.10+** (if running locally without Docker)
- A Steam Account with a public Steam Web API Key.
- A Discord Server/Channel (for Webhook notifications).

## 🚀 Installation

### 1. Clone the repository
```bash
git clone https://github.com/Nathan-Camredon/SteamBundleBot.git
cd SteamBundleBot
```

### 2. Environment Configuration
Copy the example environment file and fill in your credentials:
```bash
cp .env.example .env
```
**`.env` variables**:
- `STEAM_API_KEY`: Your key generated from the Steam API page.
- `STEAM_ID`: Your public SteamID64.
- `DISCORD_WEBHOOK_URL`: The URL of your Discord Webhook (created in your server's channel integrations).

## 💻 Usage

The project comes with a ready-to-use Docker environment. This is the recommended method for running the bot continuously in the background.

### Option 1: Using Docker (Recommended)
Launch the container in the background using Docker Compose:
```bash
docker-compose up -d
```
*Note: Your `steambundlebot.db` database is safely mounted to the local `data/` folder, ensuring your history persists across container restarts.*

### Option 2: Local Execution
Install the dependencies and start the main script:
```bash
pip install -r requirements.txt
python main.py
```
*Note: The algorithm incorporates intentional `time.sleep()` delays to rigorously respect Steam's API rate limits and prevent IP bans. Do not reduce these limits.*

## 🏗️ Architecture Overview

The project adheres to SOLID principles with a clear separation of concerns:
- `src/` : Core business logic (Extractors, EV Calculations, `Game` & `Bundle` models).
- `src/utils/` : External connectors (Discord Notifier).
- `data/` : Directory containing the auto-generated SQLite database.
- `main.py` : The central orchestrator and scheduler.
